# UI Enhanced Product Customizer (React + Vite + TypeScript)

This app renders a product customization page with an enhanced, modern color system and accessible swatches—similar to the provided mock.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed in the terminal.

## Explore

- `src/index.css` — theme tokens (light/dark) and utilities.
- `src/App.css` — layout and component styles.
- `src/App.tsx` — UI, state, and live price calculation.
